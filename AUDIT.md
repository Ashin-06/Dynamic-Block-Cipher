# Implementation audit — 2026-10-09

Scope: core cipher/API, command-line file handling, Tk GUI worker flow, optional hybrid exchange, tests, and public documentation. This is a source-level implementation review with regression tests, not independent cryptographic certification.

## Fixed

| Finding | Change |
| --- | --- |
| CLI/GUI could overwrite source or existing output | New output names, collision refusal, atomic no-replace publication |
| Password required on command line | Hidden prompt, encryption confirmation; positional form retained |
| GUI stripped plaintext and clipboard whitespace | Exact text retrieval excluding only Tk's synthetic final newline |
| Background threads touched Tk widgets | Main-thread event queue, serialized jobs, shutdown timer cleanup |
| Keys were left populated after some exceptions | `finally` cleanup and context-manager API |
| Malformed ciphertext reached expensive or partial processing | Minimum full payload and block alignment validation before KDF |
| XOR silently truncated mismatched input | Explicit equal-length validation |
| Permutation argument was ignored | Honor custom permutations and validate tables |
| Low-level invalid blocks/padding were inconsistently accepted | Block, subkey, and padding-size validation |
| Missing PQ dependencies silently produced mock secrets | Require real backends and ML-KEM-768; remove mock branches |
| Demo truncated the shared secret | Use the complete shared-secret hex in the integration example |
| Unsupported security/quantum and performance claims | Replace with measured behavior and documented limitations |

## Remaining limitations

The diffusion layer has a structural repeated-output weakness, documented with a regression reproducer in [SECURITY.md](SECURITY.md). Its wire behavior is retained solely for existing educational samples. This cipher cannot be described as production-grade. Replacing it requires a separately versioned design, migration support, and cryptographic review.

The optional native PQ integration is not verified on hosts lacking its dependencies. The exchange is unauthenticated. Files are processed in memory, Python secret erasure is best effort, and atomic file publication requires hard links. CI and GUI smoke tests do not replace independent cryptanalysis or exhaustive platform testing.
